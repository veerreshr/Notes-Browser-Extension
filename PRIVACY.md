# Privacy Policy for Site Notes

Effective date: September 8, 2026

Site Notes is a browser extension that lets users create notes associated with a website URL or domain.

## Information the Extension Accesses

Site Notes accesses the URL and domain of the active browser tab so it can display and organize notes for the current website.

The extension stores the following information locally in the user's browser profile:

- Note text entered by the user
- The URL and domain associated with each note
- Note identifiers and creation and update timestamps
- The user's selected note scope preference

## How Information Is Used

This information is used only to provide the extension's note-taking, organization, and storage-management features.

## Storage and Sharing

Notes and settings are stored locally using the browser's extension storage API. Site Notes does not operate a developer-controlled server, require an account, sell user data, or use user data for advertising or analytics.

To display a website icon, Site Notes requests a favicon from Google's favicon service using the current website's domain. This request may disclose the domain and standard network information, such as the user's IP address, to Google. Google's handling of this information is governed by the [Google Privacy Policy](https://policies.google.com/privacy).

## Data Retention and User Controls

Information remains in the user's browser profile until the user deletes an individual note, deletes all notes for a domain through the extension's storage manager, clears the extension's browser storage, or uninstalls the extension.

## Security

Site Notes relies on the browser's extension storage and security mechanisms to protect locally stored information. No method of electronic storage is guaranteed to be completely secure.

## Changes to This Policy

This policy may be updated when the extension's data practices change. Updates will be published on this page with a revised effective date.
